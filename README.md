✅4. 주요 기능 소개

➡️1) 노인 다이용 역 지도
- 지하철 노선도가 표시된 지도 위에 노인 아이콘으로 노인 이용률 상위 역을 확인 가능

➡️2) 시간대별 승하차 - 주변시설
- 시간대별 노인 이용률 상위 역 수를 설정한 뒤,
- 출근 피크, 낮 시간, 퇴근 피크, 그 외로 구분하고
- 승하차 동시 표시, 승차만 표시, 하차만 표시로 구분하여
- 전반적으로 어떤 구역에서 노인이 승차하고, 하차하는지를 시간대별로 확인 가능

➡️3) 적자 회복 시뮬레이터
- 호선, 시간대별로 노인 부담 요금을 다르게 입력하면 손실 회복률을 막대그래프로 표시
- 제도 개선 전과 후를 비교할 수 있도록 두 개의 막대그래프로 표시



✅5. SQL문

➡️1) 노인 다이용 역 지도
SELECT u.역명, co.위도, co.경도, u.노인_연간이용
FROM (
  SELECT 역명,
         SUM("6시"+"7시"+"8시"+"9시"+"10시"+"11시"+"12시"+"13시"+"14시"
            +"15시"+"16시"+"17시"+"18시"+"19시"+"20시"+"21시"+"22시"
            +"23시"+"24시"+"25시") AS 노인_연간이용
  FROM 노인이용 GROUP BY 역명
) u
JOIN 역좌표 co ON u.역명 = co.역명
ORDER BY u.노인_연간이용 DESC
LIMIT 10;


➡️2) 시간대별 승하차 - 주변시설
SELECT
  SUM(u.am)            AS 출근피크_노인승차_연간,
  SUM(u.mid)           AS 한가시간_노인승차_연간,
  SUM(u.pm)            AS 퇴근피크_노인승차_연간,
  ROUND(AVG(c.am),1)   AS 출근피크_평균혼잡도,
  ROUND(AVG(c.mid),1)  AS 한가시간_평균혼잡도,
  ROUND(AVG(c.pm),1)   AS 퇴근피크_평균혼잡도
FROM (
  SELECT 역번호,
         SUM("7시"+"8시"+"9시")                                AS am,
         SUM("10시"+"11시"+"12시"+"13시"+"14시"+"15시"+"16시")  AS mid,
         SUM("18시"+"19시"+"20시")                              AS pm
  FROM 노인이용 WHERE 승하차='승차' GROUP BY 역번호
) u
JOIN (
  SELECT 역번호,
         AVG(("7시"+"8시"+"9시")/3.0)                               AS am,
         AVG(("10시"+"11시"+"12시"+"13시"+"14시"+"15시"+"16시")/7.0) AS mid,
         AVG(("18시"+"19시"+"20시")/3.0)                            AS pm
  FROM 혼잡도 GROUP BY 역번호
) c ON u.역번호 = c.역번호;
